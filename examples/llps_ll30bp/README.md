# Phase Separation of 45 12-Nucleosome Fibers (30-bp Linkers) with Linker Torsion

## Description

Liquid–liquid phase separation in a slab box, with 45 12-nucleosome fibers in a 100 × 100 × 1000 nm³ box as in the slab simulations of the NICG paper. The fibers have 30-bp linkers (NRL 177 bp) and the linker torsion on. A condensate spans the short x and y directions, so it forms a slab across the box, and the concentrations of the condensed and dilute phases can be read from the density profile along z.

The builder writes one system from many chains, each with its own chain file, and places a chain along its `cg` backbone. `setup_fibers.py` writes these files: the backbone of each fiber is 2 points, its start and end, 600 Å apart along z. The fibers sit on a 3 × 3 × 5 lattice: 333 Å apart in x and y, 740 Å apart in z. The builder option `-box` sets the slab box.

## Files

- `setup_fibers.py`: Writes the chain files and backbones of the 45 fibers and the list of chains
- `chains.txt`: List of the 45 chain files, generated by `setup_fibers.py`
- `fibers/chain_XX.txt`: Chain composition of fiber XX (12 nucleosomes, linker lengths in bp, backbone), generated by `setup_fibers.py`
- `fibers/path_XX.txt`: Backbone of fiber XX (start and end, Å), generated by `setup_fibers.py`
- `in.bond_settings`: Bond parameters, generated by chromatin builder
- `in.dihedral_settings`: Linker torsion parameters, generated by chromatin builder
- `in.run`: LAMMPS simulation script
- `run.sh`: Execution script
- `data.chromatin`: LAMMPS data file, generated by chromatin builder
- `chromatin.pdb`: 3D structure, generated by chromatin builder

## Simulation Details

- **System**: 45 fibers of 12 nucleosomes (540 nucleosomes, 13365 beads)
- **Linker DNA**: 30 bp (3 beads) between nucleosomes, no DNA at the fiber ends
- **Box size**: 1000 × 1000 × 10000 Å³, periodic; nucleosome concentration 90 μM over the box
- **Temperature**: 300 K
- **Salt concentration**: 150 mM
- **Interactions**: the default parameters of the model (as in `n12nrl189`)
- **Linker torsion**: helical repeat 10.5 bp/turn, nucleosomal DNA 146 bp, twist persistence length 75 nm, linker-length sd 1 bp
- **Ensemble**: NVT (Langevin thermostat)
- **Timestep**: 10 fs; 10⁸ steps (1 μs), a frame every 10⁵ steps (1000 frames)

`in.run` is the one of `n12nrl189_torsion`, except that the center of mass is not fixed (`fix recenter` is commented out).

The builder places the linker beads evenly between nucleosomes placed along a backbone. With 3 beads per linker the linker DNA bonds start at 32.3 Å (35 Å at rest), which the dynamics relaxes in the first steps. With other linker lengths check these bonds: with 2 beads (25-bp linkers) they start at 43 Å, and many DNA ends unwrap in the first few hundred steps unless the energy is minimized first.

The run takes about 2 s per 1000 steps on 4 CPU threads, about 2.5 days for the 10⁸ steps.

## How to Run

```bash
# Write the fiber inputs, build the system and run the simulation
./run.sh
```

Or step by step:

```bash
# Write chains.txt and fibers/
python3 setup_fibers.py

# Build the system in the slab box with the linker torsion
nicg_chromatin_builder.py -f chains.txt -o chromatin.pdb -d data.chromatin -b in.bond_settings -box -500 500 -500 500 -5000 5000 \
    -twh 10.5 -twN 146 -twC 75 -twsL 1 -t in.dihedral_settings

# Run simulation (or on 4 threads: export OMP_NUM_THREADS=4 ; lmp -sf omp -pk omp 4 < in.run)
lmp < in.run
```

To view the trajectory:

```bash
vmd chromatin.pdb run.dcd
```
