# 12-Nucleosome Fiber (NRL 189bp) with Linker Torsion

## Description

The fiber of the `n12nrl189` example with the linker torsion switched on. The linker lengths are given in bp (`llbp`), as the torsion requires, and the torsion parameters are set explicitly on the builder command line, so the example stays the same if the builder defaults change.

## Files

- `input.txt`: Chain composition (12 nucleosomes, linker lengths in bp)
- `chains.txt`: Points to input file
- `in.bond_settings`: Bond parameters
- `in.dihedral_settings`: Linker torsion parameters, generated by chromatin builder
- `in.run`: LAMMPS simulation script
- `run.sh`: Execution script
- `data.chromatin`: LAMMPS data file, generated by chromatin builder
- `chromatin.pdb`: 3D structure, generated by chromatin builder

## Simulation Details

As in `n12nrl189`, with in addition:

- **Linker torsion**: helical repeat 10.5 bp/turn, nucleosomal DNA 146 bp, twist persistence length 75 nm, linker-length sd 1 bp
- **Changes in `in.run`**: `comm_modify cutoff 400.0`, because the dihedrals are longer than the pair cutoff; `include in.dihedral_settings`; the angle and dihedral energies in the thermo output

The bead model is the same as in `n12nrl189`: `chromatin.pdb` and `in.bond_settings` are identical, and `data.chromatin` only adds the dihedrals.

## How to Run

```bash
# Build system and run simulation
./run.sh
```

Or step by step:

```bash
# Build chromatin fiber with the linker torsion
nicg_chromatin_builder.py -f chains.txt -o chromatin.pdb -d data.chromatin -b in.bond_settings -hbox 400.0 \
    -twh 10.5 -twN 146 -twC 75 -twsL 1 -t in.dihedral_settings

# Run simulation
lmp < in.run
```
